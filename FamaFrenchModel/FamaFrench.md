# TCN-MarketGAN — Implementation Notes

## Overview

This folder contains the TCN-MarketGAN implementation. The model generates realistic synthetic daily log-returns for **20 large-cap US equities** using a WGAN-GP framework with a Temporal Convolutional Network (TCN) backbone, conditioned on Fama-French 3 factors and Welch-Goyal macro variables.

The generative equation is:

```
r_t = α_t + β_t · F_t + σ_t · ε_t
```

where `α_t`, `β_t`, `σ_t` are stochastic TCN-generated corrections to rolling OLS estimates, and `ε_t` is idiosyncratic noise generated by the Residual Generator. Cross-asset correlation structure is learned implicitly through adversarial training.

## Factors — Fama-French 3

Loaded from `data/factors/fama_french_daily.csv` (Ken French Data Library).

| Factor | Definition |
|--------|-----------|
| `Mkt-RF` | Excess market return (CRSP value-weighted minus risk-free rate) |
| `SMB` | Small Minus Big (size factor) |
| `HML` | High Minus Low (value factor) |

Used in a rolling OLS regression (252-day window) to estimate per-asset `alpha_hat`, `beta_hat`, `sigma_hat` at each timestep. The TCN then learns stochastic corrections to these rolling estimates rather than predicting raw returns directly.

## Macro Conditioning Variables — Welch-Goyal (2008)

Following the MarketGANs paper. Sourced from **FRED** and **Yahoo Finance** 

| Variable | Definition | Source | Transformation |
|----------|-----------|--------|----------------|
| `tbl` | 3-month T-bill rate | FRED (TB3MS) | Monthly to daily ffill, z-score |
| `tms` | Term spread = 10Y Treasury minus 3M T-bill | FRED (GS10 minus TB3MS) | Monthly to daily ffill, z-score |
| `dfy` | Default spread = Baa minus Aaa corporate yield | FRED (BAA minus AAA) | Monthly to daily ffill, z-score |
| `svar` | Realized stock variance (sum of squared daily S&P 500 returns within month) | Yahoo Finance (^GSPC) | Monthly to daily ffill, z-score |

Processing pipeline:
```
FRED monthly + Yahoo Finance daily
  -> merge to monthly
  -> forward-fill to business days
  -> z-score normalize
  -> save to data/macro/welch_goyal_features.csv
```

## Architecture

### Generator 1 — Coefficient Generator (Main TCN)

Generates stochastic corrections to rolling OLS estimates. One shared TCN backbone with 3 separate output heads for alpha, beta, sigma.

| Component | Value |
|-----------|-------|
| Input channels | num_covariates (4) + latent_dim (10) = **14** |
| Hidden channels | **80** |
| Residual blocks | 6 |
| Kernel size | 2 |
| Dilation base | 2 (exponential: 1, 2, 4, 8, 16, 32) |
| Receptive field size | **127 timesteps** |
| Dropout | 20% |
| Output heads | Linear(80 -> 20) x2 for alpha and sigma; Linear(80 -> 60) for beta (20 assets x 3 factors) |

### Generator 2 — Residual Generator (Simplified TCN)

Generates idiosyncratic residuals. Kernel size 1 means it only sees the current timestep — residuals are intentionally contemporaneous with no temporal memory.

| Component | Value |
|-----------|-------|
| Input channels | num_covariates (4) + latent_dim (10) = **14** |
| Hidden channels | **80** |
| Residual blocks | 6 |
| Kernel size | 1 |
| Dilation base | 1 |
| Receptive field size | **1 timestep** |
| Dropout | 20% |
| Output head | Linear(80 -> 20) |

Cross-asset correlation structure is **not imposed explicitly**. The generator produces a joint N-dimensional return vector, and the discriminator sees the full joint distribution. The discriminator penalizes the generator whenever correlations look unrealistic, so dependence structure emerges naturally from adversarial training.

### Critic (Discriminator)

| Component | Value |
|-----------|-------|
| Input channels | num_assets (20) + num_covariates (4) = **24** |
| Hidden channels | **160** |
| Residual blocks | 6 |
| Kernel size | 2 |
| Dilation base | 2 |
| Receptive field size | 127 timesteps |
| Dropout | 20% |
| Output head | Linear(160 -> 1), mean-pooled over time |

## Evaluation Plan (Post-Training)

Per professor's feedback, evaluation must go beyond average correlation matrices:

1. **Rolling correlation** — compare real vs generated correlation matrices over time (stricter test than average Frobenius distance)
2. **Held-out test set** — generate synthetic returns over 2024-2025, compare distribution statistics to real 2024-2025 data
3. **Volatility fidelity** — vol ratio real vs generated per asset
4. **Stylized facts** — fat tails, volatility clustering, leverage effect

---

## Professor Feedback

1. **Scale test first** — Start with 20 stocks, verify model works, then increment asset classes slowly to find where it breaks.
2. **Rolling correlations** — Average correlation matrices are not sufficient. Need rolling correlations over time, real vs generated directly.
3. **Assumptions audit** — Document all assumptions, verify paper replication, then test where they break.
4. **Core skepticism** — GANs may not be capable of generating realistic synthetic multi-asset data.
